# 1.0 界面与归因体验改版

目标：让用户快速回答“这个程序或网站走代理还是直连？”以及“谁消耗了代理流量？”。

## 已实现

- 导航“累计”改为“用量”。默认今天、代理优先；时段、程序 / 网站 / 节点切换常驻。
- 用量摘要突出代理消耗；直连、总量、结果数分层展示，明确统计为当前筛选结果。
- 程序名和箭头合并为展开入口。网站缩进、数值对齐；连接设置、查看连接、置顶等统一移至行尾菜单。
- 实时页加入网站维度，可展开关联程序，再查看限定网站与程序的连接。筛选“有代理连接”保留同一对象的直连信息，避免把混合连接显示成纯代理。
- 实时摘要区分连接采样速率与内核速率。网站实时列表明确显示当前连接字节，避免与历史用量混淆。
- 程序身份、完整路径和统计范围改为按需展开。键盘可展开、使用菜单、Escape 关闭并返回焦点。
- 页面返回保留筛选、展开、滚动位置和操作焦点；定时刷新保留已展开说明。
- 新增网站到程序的历史归因数据。只使用保留期限内的程序网站明细，不用程序终身累计补造历史；说明未知、拒绝及明细缺失的范围。

- Node 前端检查通过：IPv6 和域名匹配、子域边界、代理排序、网站反查渲染、混合连接筛选。
- 页面 JavaScript 语法与修改的 Python 文件编译检查通过。
- 已在实际运行页面验证：默认筛选、程序网站展开、行尾菜单、Escape 焦点、网站 → 程序 → 连接、返回后的展开与焦点恢复；未出现页面错误日志。

## 验收边界

- 当前运行实例仍为 0.9.12 后端；前端随刷新生效。新的网站历史反查接口需要重启更新后的 Monitor。
- 隔离预览服务已提供 `tools/preview_ui.py`，本轮启动后浏览器连接超时；未将该预览计为浏览器通过项。
- 当前浏览器的窗口尺寸控制未生效，实际始终为 1280 像素。本轮已加入窄窗口布局规则，窄窗口视觉验收仍待完成。
- 未运行完整浏览器自动回归；已有工具的导航与菜单入口已同步更新。此前发布审查记录的全量测试环境限制仍需处理。
- 本轮没有提升版本号、构建发布包或发布 1.0.0，发布结论仍以完整回归和剩余审查事项为准。

## 后续体验修正（2026-10-20）

- 小球视图增加常驻“返回列表”、Esc 返回；程序 / 网站按钮直接进入对应列表。切换保留搜索和选中程序，URL 记录小球视图状态。
- 无原生图标的程序使用 6 种低饱和几何图标，按程序名稳定分配。真实图标优先；列表、历史和小球共用同一套图标。停止把 Windows 默认应用图标当作原生图标，缓存版本随之更新。
- 实时程序展开改为顶部操作栏 + 通栏网站列表，移除重复的路由与速率、等宽双栏；身份路径继续折叠。
- 程序、网站及网站下的程序均提供断开入口，只提交对应的内核连接 ID；支持批量、重复点击保护和部分失败反馈。未受内核管理的连接禁用并说明原因。断开是当前连接操作，程序可能自动重连。
- 113 项相关 Python 回归通过，两个 Node 行为检查通过。实际页面验证一键返回、Esc 返回、从小球切换网站、展开布局与断开入口；未操作用户的真实连接。
- 单独运行 HTTP 测试时，28 项中 5 项通过、23 项被 `WinError 10013` 本机 socket 权限阻挡，不能计为集成通过。新图标提取逻辑需重启更新后的 Monitor 才生效；本轮截图仍使用正在运行的旧后端图标。
