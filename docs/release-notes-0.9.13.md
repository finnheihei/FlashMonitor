Windows x64 用户请下载 **FlashMonitor-0.9.13-setup.exe**，双击安装。

- 实时页按程序 / 网站查看代理、直连与混合连接；展开后直接查看网站及断开当前内核连接。
- 用量页默认显示今天的代理消耗，支持程序与网站交叉查看，并说明历史明细保留范围。
- 小球视图增加“返回列表”和 Esc 返回；缺少原生图标的程序使用 6 款稳定分配的通用图标。
- 改进流量归因、退出保存、连接设置与界面操作。

安装前请从托盘退出正在运行的 Flash Monitor。安装在当前用户目录，正常无需管理员权限；卸载保留流量记录。需要 Microsoft Edge WebView2 Runtime。

`FlashMonitor.exe` 是单独的程序文件，供已有用户更新；首次安装优先使用 `setup.exe`。`SHA256SUMS.txt` 可用于校验下载文件。安装包和程序尚未代码签名。

断开仅针对内核管理的当前连接，程序可能自动重连；绕过内核的连接暂不支持断开。此版本属于 1.0.0 发布前的改进版本。
