# IPv6 限制：简化原生设置辅助

首页“IPv6 限制方案”和看用量“Ban IPv6”共用同一方案和当前核验状态。

选好应用/网站后，Monitor 只需点一次“继续在 FlClash 设置”。它自动核实当前对象和配置、重新绑定无活动操作的旧草稿、保存本地方案、准备归属基线并复制 AND 内容。无需另点预览、保存或准备。真实配置/控制器范围变化时会明确提示并要求确认，不会静默扩大身份范围。

客户端操作仍由你完成：进入 FlClash 当前配置的“覆写 → 标准 → 附加规则 → 新增”，选择类型 AND、粘贴复制的内容、目标 REJECT，不选全局规则。保存后退出整个覆写页让客户端应用。返回 Monitor 会自动只读核验，无需再点核验。

状态依次区分“等待保存”“已保存、等待客户端应用”“IPv6 规则已启用”。最后一个状态表示持久规则、生成文件和核心运行规则顺序一致，并不是已经观测到所有请求被阻断。限制只作用于经过 FlClash、已识别 IPv6 目标的新连接，不保证 IPv4 回退；fake-ip、不可见域名、代理远端解析和绕过核心的流量有覆盖边界。

可以一次选择多个应用和网站，最多32个，合成一条组合限制。撤销整条规则会撤销整组选定范围；此版不提供独立多条托管规则或按成员部分撤销。另一条活动/未完成原生方案必须先安全撤销核验，不能直接解除旧执行器限制。

“撤销限制”按对象名称展示指引：在当前配置附加规则中，只删除类型 AND、目标 REJECT、完整内容与详情一致的唯一一条。不要查隐藏数据库ID，不删除同文旧规则，不恢复旧整份配置。保存退出后 Monitor 自动核验持久删除与运行撤销，保留无关规则。

复制、导出、完整路径、规则内容和技术配置ID收在详情。活动窗口每2秒核验，成功后30秒一次；关闭窗口即停止。等待超过2分钟会暂停，返回窗口或点“继续核验”恢复。编译过渡或读取变化会重试，不当成已启用。

当前能力是 assisted_readonly。没有验证可用的原生自动填充/提交桥接，不是选对象就自动生效；Monitor 不写 FlClash、重载、断开连接或修改系统网络。
