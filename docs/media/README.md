# 宣传图片

本目录包含为项目首页制作的 AI 生成功能示意图，采用白色、蓝色与绿色的简约视觉风格。

| 文件 | 展示重点 |
| --- | --- |
| hero.webp | 程序、网站、代理与直连的核心定位 |
| usage.webp | 按程序、网站、节点查看用量 |
| sites.webp | 程序与网站之间的双向查看 |
| control.webp | 单条与按范围断开内核连接 |

这些图片不是实际界面截图。图中应用、网站、数值与连接路径均为示意，不代表实际路由、实测性能或用户使用记录。功能限制以项目首页与使用说明为准。

图片以 WebP 格式保存以减少首页加载量；替换时请保留示意或截图来源说明。
