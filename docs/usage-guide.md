# 使用与开发说明

[← 返回项目首页](../README.md)

这里保留完整的使用说明、实现边界和各版本行为记录。快速了解核心功能与下载入口请看项目首页。

Windows 上给 [FlClash](https://github.com/chen08209/FlClash) / Clash Meta（mihomo）用的本机流量监视。看哪个程序走代理、哪个走直连、流量去了哪个网站。TUN 和系统代理都能用。

桌面窗口（WebView2）+ 托盘。关窗口默认进托盘，采集不停。只监听 `127.0.0.1`，流量记录留在本机。

顶栏的「↻」可立即重新读取连接、累计用量和节点清单。刷新期间防止重复点击，失败时保留原页面数据并提示重试；不会重启代理、清空统计或切换代理组。需要运行 0.9.7 或更新的后端；旧源码实例重新加载页面后会禁用此按钮。

当前源码中，顶部「查看」菜单只切换列表与小球。检查更新和卸载说明在「设置 → 关于」；「设置 → 数据 → 高级维护」默认折叠，收纳打开安装目录、复制诊断信息、规则草稿与旧 IPv6 方案。下方带版本号的段落保留各版本行为记录，旧截图可能仍显示此前入口。

## 安装

打开 [GitHub Releases 下载页](https://github.com/finnheihei/FlashMonitor/releases/latest)，下载 **FlashMonitor-0.9.14-setup.exe** 后双击安装，不用装 Python。安装前从托盘退出正在运行的 Monitor。

安装至 `%LOCALAPPDATA%\FlashMonitor`，在开始菜单创建快捷方式，正常无需管理员权限。需要 Microsoft Edge WebView2 Runtime；Clash 客户端要先打开外部控制器。卸载入口在 Windows“已安装的应用”，默认保留流量记录。安装器不自动搬移其他目录的旧数据，迁移说明见 [安装文档](windows-installer.md)。

同一发布页的 `FlashMonitor.exe` 是独立程序文件，供已有用户更新；首次安装优先使用 `setup.exe`。下载文件可用 `SHA256SUMS.txt` 校验。

## 能做什么

- **一键屏蔽 IPv6**：从应用或网站行尾菜单打开「IPv6 屏蔽」，或从「设置 → Clash 接入 → 选择应用或网站」选择范围，打开「屏蔽 IPv6」开关即可生效，关闭本条规则后，若仍受其他规则限制，窗口会列出相关范围并提供查看入口。从应用或网站进入时直接显示当前对象与开关，不再恢复诊断草稿或要求选择代理组；路径缺失时明确提示重试。支持多个独立范围、网站精确 / 子域匹配和某应用中的指定网站。IPv4 保留原代理 / 直连规则及已选代理节点，无需选择诊断代理组。

限制由 Monitor 保存到 `scoped-ipv6.json` 并在运行期间维护，每 5 秒核实；关闭窗口到托盘可继续维护。客户端重载后可能短暂失去限制，核实同一配置后恢复；切换配置或控制器不会把旧范围应用到新目标。退出 Monitor 后不再维护；核心已加载的限制会保留至客户端下次重载。应用 / 撤销需要重载核心，可能短暂影响连接。仅屏蔽核心识别到的 IPv6 目标新连接，不保证应用自动回退 IPv4，也不控制代理远端解析、fake-ip 或绕过核心的流量；严格强制 IPv4 仍未提供。此功能不写 FlClash 数据库或订阅 / 生成文件，也不声称是 FlClash 原生附加规则。兼容条件与恢复机制见 [执行说明](scoped-ipv6.md)。

- **实时**：按程序或网站查看代理、直连、混合、未知及绕过 TUN 的连接。点程序展开通栏网站列表，可查看用量、进入连接明细，或直接断开该程序 / 网站的当前内核连接。启用订阅显示且能读取用量时，列表上方显示可展开的订阅摘要，提供已用、可用的剩余额度和到期信息，展开可刷新账期。配置了订阅但读取失败时，保留失败说明与重试；旧数据会标明缓存或失败状态及可用的更新时间。更换订阅不会沿用其他套餐的余额。顶部速率统计全部连接，不随列表筛选改变；列表单独显示匹配数量与总数。小球视图显示前 12 个活跃程序，常驻“返回列表”并支持 Esc 返回。搜索点击按钮或按 `/` 展开。
- **用量**：支持程序、网站、节点及近 1 小时 / 今天 / 7 天 / 30 天 / 累计。时段和维度筛选常驻；主指标按当前结果及流量筛选显示总用量、代理用量或直连用量，节点维度显示节点流量。程序可展开网站，网站可反查程序，明细范围不足时会说明。可比较代理和直连、钉住或忽略程序。置顶程序显示在实时列表前方；用量榜严格按数值排序，置顶只保留标记；重复点击当前维度不会重置程序范围和排序。忽略项从程序列表隐藏，网站与节点总量仍包含它们的流量，页面会说明统计范围。搜索提示随维度变化。CSV 导出当前显示的统计结果，程序保留显示名称与进程名，流量列标明字节，并附统计时段、可用的记录起点和导出时间。
- **筛选与提醒**：连接和用量页显示当前筛选标签与清除入口，空结果也可直接清除筛选。普通提醒合并到可折叠区域，可选择「今天收起」，新提醒仍会更新数量；统计未保存、清零待保存等存储错误独立常显，不随普通提醒一起收起。
- **异常**：标题栏统一提示绕过 TUN 的连接，点击进入筛选后的连接视图
- **连接**：从实时页的「全部连接」或程序详情进入，切换实时 / 最近结束；支持单条及按程序 / 网站批量断开内核连接，失败和部分成功会提示。后台断线时标明旧数据并禁用断开；绕过内核的连接暂不支持断开，程序也可能自动重连。
- **设置**：启动、通知、Clash 接入（含机场账期与 IPv6 屏蔽入口）、数据、关于。首次读取失败时显示重试，不展示可编辑的空配置；普通开关保存失败会恢复已确认值，并保留对应的错误与重试入口。
- **更新**：从「设置 → 关于 → 检查更新」检查 GitHub 版本并展示版本说明；点击「下载并重启」才会下载、校验并安装。最终保存成功后才进入替换重启；保存或启动替换脚本失败会显示原因并尝试恢复采集，无法恢复时会提示检查数据目录并重启。源码运行和开发实例不支持应用内安装更新，请通过 GitHub 获取新版源码或安装包。
- **单实例**：再开一次会唤起已有窗口

旧代理 / 直连草稿后端支持直连、指定实际策略组、跟随原规则（仅删除本工具草稿）；当前「IPv6 屏蔽」窗口不提供草稿编辑入口。先预览，再保存到本工具数据目录 `rule-drafts.json`，可以删除或导出标准 mihomo YAML 规则片段。所有状态均标明**未应用**，没有应用按钮；不会修改 FlClash 文件、数据库、控制器配置或共享策略组。

已保存的草稿可从「设置 → 数据 → 高级维护 → 规则草稿」访问；程序退出后仍能按保存时的身份查看、导出或删除，不重新猜测进程身份。此入口不提供离线改写规则。实时列表展示连接提供的可执行文件路径；同名多路径在详情中分别展示，速率仍明确为名称合计。

规则使用当前连接提供的实际 `.exe` 文件名，缺失、歧义或数据过期时阻止生成；不会给显示名补 `.exe`。同名进程均可能匹配，组可能选择 DIRECT。预览只核对已读取的同进程规则；完整顺序、域名/规则集遮蔽、当前模式、进程识别和订阅更新后的持久化需人工确认。导出不是完整配置，不能替换原配置；FlClash 的具体导入步骤尚未验证。草稿不会改变列表的实时代理/直连标签，也不会断开已有连接。

快捷键：`1` 实时、`2` 用量、`3` 连接、`6` 设置，`/` 搜索，`Esc` 关闭菜单、搜索或程序详情，在小球视图返回列表。连接明细里的“返回”会恢复进入前的筛选、展开、排序和滚动位置；浏览器返回同样支持恢复页面状态。

## 从源码运行

需要 **Python 3.11+** 和已打开外部控制器的 Clash 客户端。运行时只用标准库。

```bat
start.cmd
```

或 `python -u monitor.py --port 8787`。只要采集不要窗口时加 `--no-gui`；`--once` 打印一次完整数据（JSON）后退出。端口被占用时会自动往后换一个，实际地址写在 `app.log` 里。

打包：`build.cmd` → `dist\FlashMonitor.exe`。它会先跑测试、再按版本号生成 `versioninfo.txt`、最后用 PyInstaller 打包。

### 开发

代码在 `flashmonitor\` 包里，入口是 `flashmonitor\app.py` 的 `main()`；`monitor.py` 只是启动脚本。版本号只在 `flashmonitor\__init__.py` 里写一次。

```bat
python -m unittest discover -s tests
```

已有 Playwright 和 Edge 时，可运行隔离界面回归（所有请求均由模拟数据接管，不启动采集服务）：

```bat
python tools\check_ui.py
python tools\check_ux_fixes.py --output "%TEMP%\flashmonitor-ux-check"
```

截图、模拟导出和检查报告默认保存到 `%TEMP%\flashmonitor-ui-check`，可用 `--output` 指定其他临时目录。

开发时设环境变量 `FLASHMONITOR_DATA_DIR` 指向一个单独的目录（比如数据的一份副本），再换个端口运行。这样的"开发实例"用自己的数据、窗口位置和单实例锁，可以和正在用的那个同时开；它不改开机启动项和快捷方式，也不做在线更新。`tests\fake_clash.py` 可以起一个假的 Clash 外部控制器：

```bat
set FLASHMONITOR_DATA_DIR=%TEMP%\fm-dev
python tests\fake_clash.py --port 19090
python monitor.py --no-gui --port 8790
```

（在设置 → Clash 接入里把外部控制器改成 `http://127.0.0.1:19090`。）

## 接客户端

**FlClash**：设置里打开外部控制器。默认 `http://127.0.0.1:9090`。

**Clash Verge**：打开外部控制器（常见 `127.0.0.1:9097`），把地址和 secret 填进「设置 → Clash 接入」。

## 注意

- 记录在 `%LOCALAPPDATA%\FlashMonitor\data`（源码运行也是这里）：统计在 `flashmonitor.db`（SQLite），每条结束的连接追加到 `connections.jsonl`，出错信息在 `app.log`。0.9.0 第一次启动时会把旧版的 `programs.json` / `slots.json` 导入数据库，旧文件保留不动。
- 页面只有本机打得开，别的网页也调不了它的接口：只接受发往 `127.0.0.1` / `localhost` 的请求，接口要带每次启动随机生成的令牌，跨站请求一律拒绝。Clash 密钥和订阅地址存在本机设置文件里，页面上不再显示原文。
- 关窗口默认藏到托盘。首次隐藏时会向 Windows 提交一次后台采集说明（系统通知设置可能影响显示）；关闭按钮也会标明隐藏或退出。彻底退出用托盘「退出 Flash Monitor」。
- 打包版没有代码签名，Windows 可能显示安全提示。请从本项目 Releases 获取文件并核对 SHA256；如安全软件报告风险，应先核实，不建议直接关闭防护或添加排除项。

### 进程身份与已保存方案
程序详情会解释路径来源及无法核实的原因；本机补查使用有限权限，不要求管理员。已验证的服务宿主展示宿主图标与只读服务列表，多服务宿主不会把全部流量归给其中一个服务。图标按本地路径及资源版本缓存，使用两个后台工作线程和最多 64 个待处理任务；无法取得专属图标时，从 6 款简约通用图标中按程序名稳定分配。

程序行可右键或按 Shift+F10 打开常用操作：查看连接、查看累计、复制完整路径、打开所在文件夹、忽略切换。未知或多身份路径的文件操作会禁用；打开目录前再次核验活跃进程身份。

用量页点击程序名称或箭头查看域名/IP/未知目标及流量，沿用既有网站归并（部分子域合并）。按程序的网站分时明细独立存入 `program-sites.db`，固定保留7天；启动和每次刷盘清理过期行，查询也排除过期记录。主文件由 SQLite 页数限制在8 MiB，最多20,000行，待写与正在写入的记录合计最多2,000条，每个身份/网站键最多512 UTF-8字节。超限舍弃较旧或无法接收的明细并提示缺失，程序总累计与原统计保留设置不变；不使用累计或当前连接补造启用前的网站历史。原有“全部”网站累计继续保留。

明细使用 DELETE 回滚日志，不产生持续增长的 WAL；事务期间仍需要额外的临时回滚日志空间，8 MiB指明细数据库主文件，不是整个数据目录的容量。未知、损坏或既有超预算的明细文件不会被覆盖，界面提示不可用，程序总累计继续保存。

正常退出先停止新采集，有限等待已发起的后台任务，再确认最终刷盘和主库WAL检查点成功，才释放窗口与存储资源。每次停止/最终保存尝试最多等待8秒，后台写盘超时不阻塞窗口、不重复启动写盘线程；超时、写盘失败或检查点被读取占用时会拒绝退出、显示错误并保留统计。此时采集已暂停，可处理磁盘/权限或读取占用后从托盘重试退出。主数据库若仅在内存中，退出也会被拒绝，不能宣称已经持久保存；这种启动故障不能只靠重试退出恢复，需保留进程并另行处理数据导出/恢复。源码修复尚未自动更新已运行的旧实例，部署需单独核验。




旧 IPv6 方案与状态保留在「设置 → 数据 → 高级维护 → 旧 IPv6 方案」，仍沿用原来的辅助原生流程。一键屏蔽使用上方独立的 Monitor 运行规则，不接管旧方案。

累计页不再放 Ban IPv6 子页，原方案和执行状态通过上述「旧 IPv6 方案」入口访问。执行代码支持备份、持久规则事务、受控重载、发布确认、撤销、失败回滚和恢复；真实环境默认未授权，需要精确目标目录/profile/对象/方案指纹及重载许可，不能由网页请求自行授予。订阅或运行配置变化后停止旧方案操作并要求重新确认，不自动覆盖新配置。FlClash进程内附加规则缓存的通知机制仍需适配验收，不能把独立核心通过视为真实FlClash全链路完成。

“全部连接”是连接明细：当前出站/节点、程序身份、远端、该组连接累计上传下载和规则说明；同程序同远端同路径可合并成一行，已结束只显示最近120条。它用于查远端与路由，不是首页实时速率，也不是选定时段用量；仅有核心连接ID时可断开，本机未测得的字节不能解释成没有流量。

源码运行时，页面每次加载读取最新 `ui.html`。关闭编辑弹窗、点击页面空白处后按 F5 或 Ctrl+R 可刷新 WebView 页面，不退出采集进程，也不清零统计；新后端API是否已载入需另行核对，页面刷新不能替代后台代码更新。

列表中的长程序名称单行省略，悬停可见完整名称；搜索、可访问名称和展开详情保留完整内容及身份路径。

### 首页显示范围与新程序提示

首页可切换「全部 / 仅代理」，选择保存在本地并在重开后恢复，与累计流量筛选独立。「仅代理」包含至少有一条确定代理连接的程序（含混合、部分未知或绕过 TUN 的程序），保留完整路由标签；纯直连、纯未知及无确定代理连接的程序不包含。顶部仍显示总速率。

「知道了」只确认当时已展示的程序事件批次，确认期间新出现的事件保留；重复点击不会重复发送，失败可重试。累计主页面使用顶部导航，程序范围和连接子页面返回入口保留。

隔离回归（需要已安装 Playwright 与 Edge）：`python tools\check_home_notices.py --output "%TEMP%\flashmonitor-home-check"`。浏览器请求全部由模拟数据处理。

### 连接设置（0.9.5）

首页保留应用代理/直连与全部/有代理连接切换，累计页只做流量统计。应用和网站的“连接设置”共用范围选择，提供直接执行的 IPv6 屏蔽和可选的只读诊断。诊断预览及底部“确认（保存草稿）”仍不应用配置；实际 IPv6 限制通过其独立按钮操作。代理/直连草稿和旧 IPv6 方案继续从“更多设置”访问。

未完成的仅 IPv4 流程已从日常界面撤下，包括选项、快捷入口和继续操作提示；没有隐藏的重新进入方式。已有草稿文件与后端原样保留，不删除或迁移数据。待具备直接生效、明确反馈和恢复能力后再重新评估。

隔离回归：`python tools/check_connection_settings.py --output "%TEMP%\fm-connection-settings"`。全部请求由 fixture 拦截，不启动日常 Monitor 或真实 Clash。

### 确认诊断草稿（0.9.6）

连接设置底部“确认（保存草稿）”只保存当前界面选择到本地 settings.json，写盘成功后关闭；失败或校验不通过保留输入，关闭或 Esc 不提交。再次从通用入口打开会恢复已确认内容；应用/网站上下文优先保持当前对象，匹配的已确认草稿可恢复。仅记录范围、完整应用路径、域名与子域名选择、代理组名和两项预览兼容选项，不包含凭据或诊断结果，不会应用网络配置。失效应用/代理组保留为待核实选择，不会自动替换。仅 IPv4 仍已撤下。

### 连接设置（0.9.12）

连接设置现在只负责 IPv6 屏蔽。从应用或网站进入时自动绑定该对象；通用入口选择应用或输入域名。只在读取状态和实际执行期间暂时锁定开关；未选对象、路径缺失或核心不可用时可点击并看到具体原因和重试入口。该窗口不读取旧诊断草稿、不请求诊断清单、不提供预览或保存草稿。原诊断草稿文件和后端仍保留，不删除用户数据。规则草稿和旧 IPv6 方案移至设置的数据页。

网站统计按站点合并子域名，从统计进入时默认勾选“包含子域名”；取消后只匹配当前域名。从实时连接的具体域名进入时默认精确匹配，也可勾选包含子域名。应用支持 `Program Files (x86)` 等含成对括号的完整路径。

重载会先核对 FlClash 保存的 DNS 与生成文件，只允许修改本工具的规则。DNS 未同步、配置在执行期间改变或无法核实时停止操作；开启、恢复与自动维护共用保护，不使用旧快照覆盖当前 DNS。详细边界见 [执行说明](scoped-ipv6.md)。
