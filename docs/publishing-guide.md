## 社区发布介绍

**标题：Flash Monitor v0.9.13：查看连接去向，统计累计代理流量，按需屏蔽 IPv6**

Flash Monitor 是面向 FlClash / mihomo 用户的 Windows 本机流量监视工具，支持 TUN 与系统代理场景，正在为 1.0 做准备。

它可以按程序、网站查看代理、直连、混合和未知状态，从程序展开网站，也能从网站反查程序；提供绕过 TUN 提示、连接明细及内核连接批量断开。

用量页支持近 1 小时、今天、近 7 天、近 30 天与累计统计，按程序、网站、节点排行，区分代理与直连，并可导出 CSV。连接设置支持按应用或网站屏蔽 IPv6，具体兼容条件见项目说明。

提供 Windows 安装包，无需 Python；支持托盘采集与小球视图，流量记录保存在本机。统计不等同于服务商账单，IPv6 屏蔽不等同于严格强制 IPv4。

- [项目主页](https://github.com/finnheihei/FlashMonitor)
- [下载页面](https://github.com/finnheihei/FlashMonitor/releases/latest)
